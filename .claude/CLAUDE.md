# bird_tool_utils-python

Shared Python library for the bird suite of bioinformatic tools (aviary,
singlem, isiteuk and others), from the Woodcroft lab at QUT CMR. It is a
dependency of those tools, so a change here reaches every downstream tool.
Treat the public surface as an API even though the README says it "may change
without warning": check how the tools use a function before changing it.

## What is in the repo

| Module | What it provides | Used for |
| --- | --- | --- |
| `bird_tool_utils/__init__.py` | `SeqReader` (`readfq`/`readfa`), `in_working_directory`, `in_tempdir`, `table_roff`, `iterable_chunks` | General helpers |
| `bird_tool_utils/argparsing.py` | `BirdArgparser`, `BirdHelpFormatter`, `Example`, `str2bool` | The suite's shared CLI: coloured short help, `--full-help` man page, `--full-help-roff`, logging args, `allow_no_args=True` subcommands |
| `bird_tool_utils/pixi_deps.py` | `build_dep_defs(...)` | Generates `environment.yml` and `requirements.txt` from a tool's `pixi.toml` |
| `bird_tool_utils/release.py` | `main()`, the `bird-release-python` console script | Shared release flow for setuptools_scm packages |
| `bird_tool_utils/people.py` | Author/contact constants | Shared metadata |
| `admin/build_dep_defs_from_pixi.py` | This repo's own dep-defs script | Regenerates `admin/environment.yml` and `admin/requirements.txt` |
| `test/` | pytest suite (`test_argparse.py`, `test_sequence.py`, `test_little_bits.py`) | `conftest.py` stubs `build_manpages` |

`bird_tool_utils/version.py` is generated by setuptools_scm from the git tag.
Never hand-edit it.

## Two kinds of work here

1. **The library** (argparsing, SeqReader, pixi_deps, helpers): keep the API
   stable and add a test in `test/` for any behaviour change.
2. **The release tooling** (`release.py`): this is shared by every tool, so it
   must stay tool-agnostic. Anything specific to one tool belongs in that
   tool's own `[tool.bird_release]` table, not here. See the
   `python-packaging` skill (`.claude/skills/python-packaging/`).

## Commands

    pixi run -e dev pytest -v                 # tests (fast, no network)
    pixi run -e dev bird-release-python --version X.Y.Z   # release THIS package

Run the tests after any change to `argparsing.py`, `__init__.py`,
`pixi_deps.py` or `release.py`.

## Conventions

- Python 3.9+ target (`pixi.toml`); `pixi_deps.py` already uses 3.11 `tomllib`.
  Check before adding syntax newer than the lowest Python a downstream tool
  supports.
- PEP 8, type hints on public functions, no silent exception swallowing.
- Commit messages: `<type>: <description>` (feat, fix, refactor, docs, test,
  chore, perf, ci).
- Confirm before editing existing files, and before any push or tag push.
- This repo has no hardcoded secrets and must stay that way.
